=====================================
   THUMBNAIL IMAGES GO HERE
=====================================

Drop your thumbnail images (.jpg, .png, .webp) into this folder.

Then open script.js and update the thumbnail paths in the
CONTENT_DATA array near the top of the file.

Example:
  If you drop "trip_thumb.jpg" here, set the thumbnail to:
    thumbnail: "thumbnails/trip_thumb.jpg"

Recommended size: 300x170 pixels (16:9 ratio)
